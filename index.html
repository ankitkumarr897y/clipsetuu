Deploy this exact page on Vercel — no install step

This ships as one static page plus its assets/ folder (logo + hero image). Upload both together — the page is not a lone file, because the images live in assets/. There is no server, no database, no runtime dependency, no lockfile, no package.json and no build command. That is why the old code-pack failed on Vercel while installing a dependency that only exists inside the previous builder runtime — this version removes that dependency entirely.

  1. GitHub: create a repo named clipsetuu. Upload index.html and the whole assets/ folder to the repo root (not inside another folder, and not as a ZIP).
  2. Vercel: Add New → Project → Import the clipsetuu repo. Framework Preset: Other. Build Command: leave empty. Output Directory: leave empty / .
  3. Deploy. Vercel serves index.html as a static site. You get a free *.vercel.app link.
  4. Custom domain (optional, paid): a .com / .in domain is never free — buy one from a registrar, then add it in Vercel → Domains.

Frequently asked questions

Is ClipSetuu really free?

Yes — free and unlimited in this build, with no credit counter or paywall anywhere on the page.

Can I clip a 7-hour video?

Yes. Uploads up to 7 hours (420 minutes) are accepted. Very long files need a modern browser and enough memory; export long clips in shorter parts if recording feels slow.

Will my exported clip have a watermark?

No. Exports are watermark-free. MP4 records directly where the browser supports it; otherwise a WebM file downloads with a conversion note.

Does the YouTube / Instagram button really post?

Not yet. The buttons prepare a real publish payload from your clip and show a demo progress flow. Live posting needs real Google/Meta OAuth connections — that is Phase 2, and it is labelled demo everywhere it appears.

Can a YouTube link alone make a clip?

No, in any browser-only tool. A link gives the plan (title, thumbnail, timings). To cut real footage, upload the video file itself.
